# Giọng đọc MC (Text-to-Speech tiếng Việt)

```bash
pip install -r requirements.txt
python app.py        # mở http://127.0.0.1:5000
```
- Cần Internet (giọng Neural Microsoft: Hoài My, Nam Minh) và `ffmpeg` (tuỳ chọn, để chèn khoảng nghỉ như MC).
- Chọn phong cách MC ấm áp, chỉnh tốc độ/cao độ/âm lượng, nghe thử và tải MP3.
