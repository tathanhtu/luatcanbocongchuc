# Voice Studio (ElevenLabs)

Duyệt/nghe thử/chọn giọng ElevenLabs, đọc văn bản tiếng Việt (tự đọc số hiệu, ngày tháng, viết tắt thành chữ), tải MP3.

**Windows:** bấm đúp `chay.bat` (cần cài Python, tích "Add python.exe to PATH").
**Mac/Linux:** `pip install -r requirements.txt && python app.py`, mở http://127.0.0.1:5050

Dán khoá API ElevenLabs (elevenlabs.io → Profile → API Keys) vào ô đầu trang. Giọng ở thẻ "Thư viện" cần "Thêm & chọn" trước khi dùng; dùng giọng thư viện qua API có thể yêu cầu gói trả phí.
